應聘原因 / Motivation

我對「宣傳與視覺傳達」有著非常純粹的熱情。在我的理解中，宣傳不只是將大量的圖文塞進多媒體版面上，而是去提煉一個有趣的核心概念並傳達給大眾。

Grey APAC 堅持的創意哲學極具吸引力，雖然這是一份中學生履歷，但我渴望挑戰這個全職管理職位，把我對平面視覺、影像藝術的想法放進真實的宣傳計劃中。

核心宣傳優勢 / Strengths

在過往的學校項目與個人學習中，我主要累積了以下優勢與相關經驗：

九年繪畫背景與審美

擁有長達九年的專業繪畫學習經歷。這段深厚的藝術積累賦予了我優秀的視覺审美品味、色彩敏銳度以及空間構圖能力。

海報與排版設計

擁有海報及排版的設計經驗。日常熟練運用 Canva 進行排版與物料輸出，具備平面視覺處理能力。

良好的溝通與團隊合作

曾在小組影片製作中擔任過一次副導（Assistant Director）。這次經驗讓我學會如何在團隊中進行有效的協調與溝通，並與不同崗位的同學密切合作共同完成專案。

ANALYSIS // RISKS & BENEFITS

副創意總監職位的潛在優缺點分析

🟢 潛在優點與核心吸引力

// BENEFITS
  • 環境氣氛良好：廣告公司充滿創新氛圍與設計美感，能與優秀同行深度交流，有利於拓展新媒體與平面視覺眼界。
  • 創意成就感：能跨越媒介限制，親自把天馬行空的想法變成真實的大型宣傳骨架，落地反饋直接，帶來巨大的個人滿足感。

🔴 潛在缺點與陷阱

// RISKS & PITFALLS
  • OT 加班風險：4A 廣告代理商非常依賴客戶時程，常態性的高強度熬夜提案和修改，极易帶來過勞與心理高壓。
  • 通勤時間長途消耗：我本身居住在大埔，若辦公地點位於港島或九龍商業核心區，每日長途往返將劇烈擠壓休息和睡眠時間。
  • 工作保障受市場衝擊：廣告行業的穩定性緊扣宏觀經濟與客戶預算，面對不景氣或競標失敗時，將直接承受嚴酷的考核與淘汰壓力。
